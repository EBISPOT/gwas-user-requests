# GWAS Catalog Community

Welcome to the GWAS Catalog community repository.

Use this repository to:

* 🐛 **Report a bug**
* 💡 **Request a feature or improvement**

To **submit data to the GWAS Catalog**, see the [submission documentation](https://www.ebi.ac.uk/gwas/docs/submission).

> [!IMPORTANT]
> If you have a question or problem relating to a **specific submission**, please contact [gwas-subs@ebi.ac.uk](mailto:gwas-subs@ebi.ac.uk).

For **general questions or feedback**, contact the GWAS Catalog team at [gwas-info@ebi.ac.uk](mailto:gwas-info@ebi.ac.uk).
